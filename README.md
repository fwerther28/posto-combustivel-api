\# ⛽ API REST - Gestão de Posto de Combustível



Projeto final do curso de \*\*Desenvolvimento de API REST com Spring Boot\*\* (120h) pelo SENAI.



\## 🛠 Tecnologias Utilizadas

\* \*\*Java 21\*\* e \*\*Spring Boot 3\*\*

\* \*\*Spring Data JPA\*\* \& \*\*Hibernate\*\*

\* \*\*MySQL\*\* (Persistência de Dados)

\* \*\*Postman\*\* (Validação de Endpoints e Status Codes)



\## 🚀 Funcionalidades

\- CRUD completo de tipos de combustível e bombas.

\- Registro de abastecimentos com relacionamentos Many-to-One.

\- Persistência garantida em banco de dados relacional.

\- Validação de dados via Jakarta Validation.



\## 📋 Como Rodar o Projeto

1\. Clone o repositório.

2\. Certifique-se de ter o MySQL instalado e o banco `posto\_db` criado.

3\. Ajuste as credenciais no `src/main/resources/application.properties`.

4\. Execute via STS ou terminal: `./mvnw spring-boot:run`
